## 1. 口径与图例

### 1.1 什么是「用得着」
按铁锈地图制作全流程判定，任一阶段属常用/标准操作即算「用得着」：

| 阶段 | 含义 |
| --- | --- |
| S1 建图 | 新建、打开、保存地图/图集 |
| S2 画地形·自动映射 | 铺 Ground/Items/Units、automapping 规则 |
| S3 放单位·触发器 | 起始单位、建筑、事件/统计对象 |
| S4 图集与瓦片属性 | .tsx 图集、瓦片属性、图层规则 |
| S5 缩略图 | 生成 `*_map.png` 预览 |
| S6 导出与打包 | 导出到 `mods/maps`、打包 `.rwmod` |

### 1.2 软件状态三档
- **已做**：菜单里真有该功能入口。
- **部分·特化**：功能存在但形态不同（固定参数、只有快捷键没有菜单入口、或只在别的菜单下）。
- **没做**：软件里没有实现。

### 1.3 来源分级
- **实证**：来自用户 2026-11-15 提供的 5 张菜单展开截图，逐项读图所得。
- **静态**：来自本机 `<Tiled目录>\translations\tiled_zh_CN.qm` 与 `tilededitor.dll` 反查，用于交叉校验。
- **推断**：用户只截了一级菜单，带 ▶ 的二级子菜单未展开截图，其内容按 Tiled 1.12 已知结构推断，标 `推断·待确认`。

### 1.4 其它约定
- 「灰显」= 空文档态下不可用（多数打开地图后即可用），本身仍是菜单项，照列。
- 分隔符 `---` 保留结构但不参与判定。
- 动态项（最近文件、导出格式列表）条目数随环境变化，按「类别」列一行。
- 快捷键带 `&` 的是 Tiled 助记符，如 `文件(&F)`，表中省略 `&` 只写字母。
