# 铁锈地图编辑器 · UI 色卡

软件整体为**深色主题**。以下色值从 `rwmap/app`、`rwmap/widgets`、`rwmap/view` 的 QSS 样式表与 `QColor` 定义中提取，按出现频率与用途精选，共 43 色 / 6 组。探针脚本、测试专用色与个别一次性用色未纳入。

配图：`examples/软件UI色卡.png`

## 基础背景 Backgrounds

| 色值 | 用途 |
|---|---|
| `#14161A` | 画布最深底 |
| `#1E1E1E` | 检查器画布 |
| `#252525` | Dock 面板底 |
| `#262626` | 顶栏/状态栏 |
| `#262A30` | 工具栏/地图底 |
| `#2B2B2B` | 面板通用底 |
| `#2F2F2F` | 输入框底 |
| `#333333` | 标题栏/按钮 |
