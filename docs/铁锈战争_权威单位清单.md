# 铁锈战争单位清单（从游戏本体提取）

## 数据来源与核对方法

本清单不是手工整理，而是交叉比对游戏本体 5 个权威来源得出：

1. `game-lib.jar` 中 `com.corrodinggames.rts.game.units.UnitType` 的单位注册表（Java 常量池）；
2. `assets/units/**/*.ini` 的 `[core] name` 字段；
3. `assets/tilesets/units.tsx` 图集里的 `unit=` tile；
4. `assets/translations/Strings_zh_cn.properties` / `Strings.properties` 的 `units.<key>.name` 官方译名；
5. `assets/gui/help_unitstats.rml` 游戏内单位统计帮助页的 `unit:` 引用。

写入地图时一律使用下表的英文内部名（反引号内），中文名只用于界面显示。
虫族单位游戏简中翻译缺失，中文名按社区常用意译（西语版有官方名可参考）。

## 分类口径

共 9 类：陆军 / 海军 / 空军 / 机甲 / 工厂 / 防御 / 建筑 / 虫族 / 其他。

- **工厂**：除虫族外所有能生产单位的建筑（含机械工厂 T2、实验工厂）；
  实验室不造单位，归「其他」。
- **建筑**：含核弹发射井与反核防御；资源抽取器 / 制造仪也归建筑，
  水晶、资金箱子、供应站等资源物归「其他」。
- **虫族**：所有虫族单位，包括火蜂战机（实验单位）与虫族建筑。
- **争议条目按[中文铁锈百科单位总览](https://rustedwarfare.org/wiki/单位)归类**：
  登陆艇、实验悬浮型气垫船属地面单位，机械螃蟹（两栖侦察机器人）属海上单位。

## 两版本差异（1.14 vs 1.15）

「两版本单位一样」经核实**不成立**。1.15 比 1.14 多 5 个单位：
`heavyAAShip`（重型防空舰）、`spyDrone`（间谍无人机）、
`modularSpider_blink` / `modularSpider_speed` / `modularSpider_speedIncomplete`（模块化蜘蛛配件）。
1.14 没有任何 1.15 缺失的单位，因此当前目录以 **1.15** 为准。

## 多形态单位

游戏里「鹦鹉螺号」「飞行机甲」的浮出水面 / 上岸 / 起飞等是同一单位的不同状态，
不是独立兵种。为方便选择，目录把它们列为独立条目并按「本体(形态)」命名：

- 鹦鹉螺号：`nautilusSubmarine`(水下) → `nautilusSubmarineSurface`(水面) → `nautilusSubmarineLand`(陆地)
- 飞行机甲：`mechFlyingLanded`(陆地) ⇄ `mechFlyingTakeoff`(空中，游戏内部用 takeoff 命名)

`modularSpider_nonEmpty` 是模块化蜘蛛「武器槽已装模块」的旧状态（ini 注释写明
`#Not used anymore, just kept for old save files`），已废弃仅兼容旧存档，目录里保持隐藏。

## 常见坑

- 拼写：核弹井是 `NukeLaucher`（少一个 n），反核防御是 `AntiNukeLaucher`；
  写成 `Launcher` 游戏不认。`nukeLauncherC` / `antiNukeLauncherC` 是战役专用变体。
- 杀手虫的正确名是 `bugMeleeT31`；`lecT31` 是错误名，会让触发器被丢弃。
- `custom_tank` / `example_faction_picker` / `flare_10s` 是游戏资源里的开发占位物，
  游戏本体不认，写进波次会让地图报 `Unknown wave format` 打不开，已从目录彻底删除。
- `NULL` / `missing` 是空槽位 / 缺失占位符，不是单位，已从目录移除。
- 重新生成目录用 `rwmap/probe/build_unit_catalog.py --game <游戏根目录>`；
  脚本已加入翻译键 + 帮助页补漏，多形态译名写在 `CN_OVERRIDE`。
