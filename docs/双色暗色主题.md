# 双色暗色主题

整套暗色主题的**界面区分色**收敛为两个：

| 角色 | 色值 | 用途 |
|---|---|---|
| `INK` | `#101010` | 近黑，最底层：画布外底、面板底、工具栏底、菜单栏、状态栏 |
| `ASH` | `#242424` | 偏黑灰，抬起一层：输入框、按钮、标签页、选中项、边框、悬停 |

区分方式只剩三种：**底色深浅**（INK / ASH）、**透明度**（ASH 的半透明版本）、
**描边**（INK 描在 ASH 上，反之亦然）。

---

## 为什么文字不在这两个色里

`#242424` 压在 `#101010` 上，对比度只有 **1.2 : 1**（WCAG 正文要求 4.5 : 1），
字形能看见、内容读不出来。硬把文字塞进这两个色，界面会变成"看得见字、读不到字"。

所以**文字单独用可读浅色**，并集中在 `rwmap/theme.py` 一处：

```python
TEXT     = "#d8d8d8"   # 主文字
TEXT_DIM = "#8a8a8a"   # 次要文字 / 提示
```

想改整体明暗，只动 `rwmap/theme.py` 这几个常量即可。

---

## 功能彩色（按需求保留，不参与收敛）

这些颜色承载**语义信息**，不是界面装饰，收敛掉会丢失信息：

- **工具栏图标**本身的彩色（`_ICON_BLUE` 及各图标绘制色）
- **触发器**的连线色 / 端口色 / 节点类型色（`EDGE_COLORS` / `TYPE_COLORS` / `THEME["port_*"]`）
- **对象框、标注框、分组框**（`OBJECT_YELLOW`，黄色系）
- **抓取虚影**蓝框、**非法格**红框（`map_scene.py`）
- **选中框**（`selection_style.SELECT`，蓝色）
- **小地图视口框**（`minimap._VP`，浅蓝）
- **地图数据里的颜色**（文字样式 `TEXT_DEFAULTS["color"]`、图集透明色等）—— 这些会写进 `.tmx`，绝对不能动

## 两个容易踩的坑

**1. 原生部件不吃各面板自己的样式表**

菜单栏、状态栏、`QSplitter` 手柄、`QGraphicsView` 边框这些走 Qt 原生绘制，
在各面板里 `setStyleSheet` 管不到，会漏出系统默认的白 / 浅灰。
统一在 `theme.APP_QSS` 里接管，并挂在 `QApplication` 上：

```python
app = QApplication(argv)
apply_app_theme(app)     # rwmap/theme.py
```

`QGraphicsView` 的原生 1px 边框同样漏白，要显式关掉：

```python
self.setFrameShape(QGraphicsView.NoFrame)
```

**2. `QColor("字符串", alpha)` 在 PySide6 里不成立**

`QColor` 的重载只有 `(r, g, b, a)`，没有 `(name, alpha)`。
要半透明主题色，用 `rwmap/theme.py` 里的工厂：

```python
from ..theme import qc
painter.setBrush(qc(ASH, 110))     # 正确
QColor(ASH, 110)                   # TypeError
```
